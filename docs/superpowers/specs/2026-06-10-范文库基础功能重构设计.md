# 范文库基础功能重构设计

## 背景

范文库当前是 App 中最基础的模块：列表 → 详情 → 标注堆在底部。annotations 数据有 startIndex/endIndex 精确定位但未被渲染利用，卡片展示分数而非学习价值，详情页布局未适配精读场景。本次重构目标是把范文库的基础功能做扎实，使其成为和其他模块同等质量的产品体验。

## 数据层变更

### essays.json 字段调整

**删除字段：**
- `score` — 范文库定位是学手法而非比分数，分数信息无学习价值

**新增字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `questionId` | `string \| null` | 否 | 关联 questions.json。41 篇中约一半能匹配，不能匹配的设 null |
| `techniques` | `string[]` | 是 | 每篇 1-3 个核心写作技法标签 |

### techniques 标签体系

从现有范文 annotations 中提炼，不造新概念：

| 标签 | 含义 |
|------|------|
| 先驳后立 | 先承认对立面再推进 |
| 意象闭环 | 开头意象结尾回收 |
| 三元递进 | 三个选项不是并列而是递进 |
| 然后推进 | 承认→追问局限→新结论 |
| 经典当跳转 | 经典素材引出当下议题 |
| 比喻破题 | 用日常场景翻译抽象命题 |
| 多维展开 | 从不同维度层层深入 |
| 辩证统一 | 对立概念的融合 |

### types/index.ts

```ts
export interface ModelEssay {
  id: string;
  title: string;
  topic: string;
  genre: EssayGenre;
  category: EssayCategory;
  content: string;
  annotations: EssayAnnotation[];
  tags: string[];
  questionId?: string;
  techniques: string[];
}
```

### 前置数据工作

逐篇审读 41 篇范文，为每篇分配 `questionId`（能匹配的填入，不能的设 null）和 1-3 个 `techniques` 标签。

## 列表页重构

### 卡片布局

```
┌──────────────────────────────────┐
│ 浴火于跌宕的烟霞                  │  标题（加粗，18px）
│ 有人把得与失看成终点，有人把得与失 │  题目（line-clamp: 2）
│ 看成起点，有人把得与失看成过程...   │
│ 思辨方法  先驳后立  意象闭环        │  分类标签 + 技法标签
└──────────────────────────────────┘
```

- 题目用 CSS `-webkit-line-clamp: 2` 自然截断，不硬切字数
- 分类标签样式复用 `.essay-tag-chip`
- 技法标签样式复用 `.card-tag`（`--color-tag-bg` + `--color-tag`）

### 双维度筛选

列表页顶部两行筛选：

```
[搜索框]

全部  思辨方法  人生哲理  社会观察  ...    ← 分类筛选

全部  先驳后立  意象闭环  比喻破题  ...    ← 技法筛选
```

**筛选逻辑：**
- 两个维度是 AND 关系
- 选中分类后，技法标签列表动态更新为当前分类下出现的技法（避免选到空集）
- 选中技法同理，分类列表动态更新
- 点击已激活的标签取消筛选
- 卡片上的技法标签可点击，直接触发对应技法筛选（快捷入口）

```
│                              │                  │

│                              │                  │
│  [段落1 - 高亮]               │  ■ 立意          │
│                              │    开篇没有在三   │
│  [段落2]                      │    个选项里选...  │
│                              │                  │
│  [段落3 - 高亮]               │  ■ 论证          │
│                              │    先承认对立面... │
```

- 侧栏 `position: sticky`，固定在视口内

**移动端（≤768px）：**

```
┌──────────────────────┐
│ ← 返回      标题     │
├──────────────────────┤
│ 题目：xxx             │
│                      │
│ [段落1 - 高亮]        │
```

- 单列布局，点击高亮段落弹出底部浮层
- 浮层带拖拽手柄（顶部居中小横条，`var(--color-border)`）
- 浮层最高 70vh，背景遮罩 `rgba(0,0,0,0.3)`，z-index: 100
- 复用 `.recent-detail-overlay` 的动画逻辑
- 点击浮层外区域收起

### 文内标注渲染

**AnnotatedContent 组件：**

1. `content.split('\n')` → paragraphs[]
2. annotations 的 startIndex/endIndex 映射到段落索引：
   - 先尝试直接作为段落索引（如果 endIndex ≤ 段落数）
   - 否则按字符比例换算：`paraIndex = floor(startIndex / content.length * paragraphs.length)`
3. 跨段落边界 annotation 取覆盖的所有段落
4. 一个段落多个标注时，左侧色条只显示一条，点击后展开所有批注

**高亮样式：**

```css
.ann-highlight {
  background: var(--color-accent-soft);      /* rgba(0,212,164,0.1) */
  border-left: 3px solid var(--color-accent); /* #00d4a4 */
  cursor: pointer;
  transition: background var(--transition-fast);
}

.ann-highlight:hover {
  background: rgba(0, 212, 164, 0.18);
}

.ann-highlight.active {
  background: rgba(0, 212, 164, 0.22);
}
```

所有标注类型统一用强调色，通过 label 文字区分（复用 `.card-tag` 样式）。不引入额外颜色，保持 Mintlify 极简设计语言。

### 双向联动

- 点击高亮段落 → 侧栏/浮层对应标注 `scrollIntoView({ behavior: 'smooth', block: 'nearest' })`，标注项高亮
- 点击侧栏标注 → 正文对应段落 smooth scroll + 闪烁动画（`animation: pulse 0.6s`）
- 移动端点击侧栏标注 → 浮层收起 + 正文滚动定位

### "用此题练习"按钮

- 移到详情页顶部操作栏右侧
- 使用 `.btn-primary` 样式（强调色背景，和"开始写作"视觉权重一致）
- 如有 `questionId`，跳转写作模块并自动选题
- 如无 `questionId`，传 topic 字符串（保持当前逻辑）

## 交互细节

1. **同时只展开一个批注** — 点击新高亮段落，前一个自动收起
2. **移动端浮层行为** — 点击高亮打开，点击另一个高亮更新内容，点击浮层外收起
3. **技法筛选联动** — 选中一个维度后另一个维度的选项列表动态收窄
4. **搜索和筛选组合** — 搜索关键词 + 分类 + 技法三者 AND 关系

## 不在范围内

- 范文数量扩充（数据准备工作，非代码任务）
- 范文对比阅读
- 精读引导模式
- 写作完成后与范文对比
