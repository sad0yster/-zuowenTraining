# 辩论模式优化设计

## 概述

优化思辨素材模块的辩论模式，目标是让用户通过辩论形式逐层深度拆解素材。核心改进：Mintlify 风格 UI 重构、阶段式 AI 引导、自由切换立场、自动收获卡。

## 设计原则

- 辩论是思辨工具，不是竞技比赛——核心目标是深度拆解素材
- 用户可以随时切换正反方视角，切换本身就是思辨训练
- AI 主动引导拆解层次，但不强制推进
- 收获卡必须有"可直接用在作文里"的实用价值

## 流程设计

### 整体流程

```
[进入辩论模式]
    ↓
[AI 开场：抛出概念界定问题，显示正方/反方两个立场区域]
    ↓
[用户选择立场发言] ←→ [随时可切换立场]
    ↓
[AI 从对立面反驳 + 自然引出下一层次]
    ↓
[阶段推进：概念界定 → 对立面 → 更高维度 → 现实联系]
    ↓
[辩论结束：生成收获卡]
```

### 四阶段拆解

| 阶段 | 标识 | AI 的角色 | AI 的引导方式 |
|------|------|----------|-------------|
| 概念界定 | `concept` | 提问者 | 抛出界定问题，如「这里的 X 到底指什么？它和 Y 有什么区别？」 |
| 寻找对立面 | `opposition` | 对手 | 从用户对立面反驳，指出论点中的隐含假设和逻辑漏洞 |
| 更高维度 | `synthesis` | 引导者 | 提示「这两种观点有没有可能同时成立？」引导综合思考 |
| 现实联系 | `application` | 教练 | 问「这个思辨在你身边有什么具体体现？」连接写作素材 |

### 阶段推进机制

- 前端根据轮次控制阶段推进：每 2 轮建议进入下一阶段
- AI 在每轮回应中使用明确的过渡模板句引导阶段切换（模板句见下方 Prompt 设计章节）
- 用户可以忽略暗示继续当前阶段
- AI 不输出隐藏阶段标记，阶段追踪完全由前端控制

### 立场切换

- 用户每轮发言前通过 pill 标签切换当前立场（正方/反方）
- 默认正方，可随时切换
- 切换时 AI 主动问：「你刚才从正方角度看，现在切到反方，你发现了什么之前没注意到的东西？」

### 结束条件

- 4 个阶段全部完成 OR 用户主动结束 OR 总轮次超过 8 轮时 AI 自动提示结束
- 结束时 AI 问：「你想继续深入，还是我们来总结一下今天的收获？」
- 用户确认后生成收获卡
- 部分完成（只完成 1-2 个阶段）也生成简化版收获卡

### 卡住时的脚手架

- 如果用户论点太短（< 50 字），AI 给出迷你框架：「你的论点可以从三个角度展开：定义、证据、推理。先试试从定义开始？」

## UI 设计（Mintlify 风格）

### 设计语言

遵循 `mintlify/DESIGN.md` 中定义的设计系统：
- 颜色：主色 #0a0a0a，强调 #00d4a4，表面 #f7f7f7，边框 #e5e5e5
- 按钮：pill 形状（9999px 圆角）
- 卡片：12px 圆角 + 1px hairline 边框
- 字体：Inter，标题紧凑字间距（-0.5px），正文 14-16px
- 间距：4px 基础，24px 卡片内边距，32px 区块间距

### 关键 UI 组件

**阶段指示器**：pill-tab 组件，当前阶段用 brand-green 高亮，已完成阶段用对勾标记

**AI 引导语**：surface 背景 + 左侧 2px brand-green 边框，与论点卡片区分

**正反方论点卡片**：
- 正方：canvas (#ffffff) 背景 + hairline 边框
- 反方：surface (#f7f7f7) 背景 + hairline 边框
- 按轮次流式展示（不是左右分栏），保持对话感

**立场切换标签**：pill-tab 风格，选中态用 primary（黑底白字）

**输入区**：
- text-input 风格，120px 高
- focus 时 brand-green 边框
- sticky 底部长辩论时始终可见

**收获卡**：
- card-base 风格 + 左侧 2px brand-green 边框
- 辩论结束后替代输入区出现
- 支持复制和保存

### 响应式

- 移动端：论点卡片全宽，阶段指示器可横向滚动
- 桌面端：辩论卡最大宽度 720px 居中

## AI 引导策略

### Prompt 架构

三层组装：`ROLE_PROMPT` + `THINKING_TOOLKIT` + `DEBATE_SCENE_PROMPT`

### 开场 Prompt

辩论开始时，AI 自动生成开场引导（不是用户输入触发）：

```
你是一个思辨教练。现在开始一场关于「{material.title}」的辩论。

情境：{material.situation}
核心张力：{material.coreTension}

请用1-2句话引入辩论，然后抛出一个概念界定问题，引导学生思考核心概念的含义。

要求：
- 用苏格拉底式提问
- 问题要具体，不要太抽象
- 引导学生从定义开始思考
```

### DEBATE_SCENE_PROMPT 设计

```
你是一个思辨教练，通过辩论形式帮助学生深度拆解素材。

素材：{material.title}
情境：{material.situation}
核心张力：{material.coreTension}

当前阶段：{stage}（概念界定/寻找对立面/更高维度/现实联系）
用户立场：{side}（正方/反方）
已进行轮次：{round}

用户论点：
{userArgument}

请从对立面回应用户。要求：
1. 直接回应用户的论点，指出其中的隐含假设或逻辑漏洞
2. 提出新的视角或反例
3. 长度150-200字
4. 末尾自然引导下一阶段（使用过渡模板句）
5. 用苏格拉底式提问，不要直接给答案

过渡模板句：
- 概念界定→对立面：「我们已经界定了X的含义。现在，让我们试试完全站在反面——如果有人坚决反对你的观点，他们会怎么说？」
- 对立面→更高维度：「你已经看到了正反两面。现在问自己：这两种看似矛盾的观点，有没有可能指向同一个更深层的东西？」
- 更高维度→现实联系：「这个更高维度的理解，你觉得在现实生活中有什么具体的例子？」
```

### 收获卡 Prompt

```
请基于以下辩论记录，生成一张收获卡。

素材：{material.title}
核心张力：{material.coreTension}

辩论记录：
{rounds.map(r => `第${r.round}轮 [${r.side === 'for' ? '正方' : '反方'}]：${r.content}`).join('\n\n')}

请生成收获卡，包含以下三部分：

【核心洞察】
通过这场辩论，我们发现了什么深层思考？（2-3句话，回扣素材核心张力）

【可用论据】
从辩论中提取2-3个最有价值的论据，标注来源轮次和立场。（可直接用在作文中）

【辩证统一】
看似矛盾的两种观点，其实指向什么更高维度的理解？（2-3句话）

要求：
- 提炼而非复述，每条收获都要有"可直接用在作文里"的实用价值
- 引用具体轮次中的高光时刻
- 回扣素材的核心张力
```

### 短论点脚手架 Prompt

当用户论点 < 50 字时，追加到 AI 回应中：

```
你的论点可以更充实。试试从这三个角度展开：
1. 定义：你所说的核心概念具体指什么？
2. 证据：有什么例子或权威观点支持你？
3. 推理：从你的前提出发，能得出什么结论？
先试试从定义开始？
```

## 数据模型

### 类型定义

```typescript
// 辩论阶段
export type DebateStage = 'concept' | 'opposition' | 'synthesis' | 'application';

// 辩论立场
export type DebateSide = 'for' | 'against';

// 辩论轮次
export interface DebateRound {
  round: number;
  side: DebateSide;
  content: string;
  isUser: boolean;
  timestamp: number;
  stage: DebateStage;
}

// 辩论记录
export interface DebateRecord {
  id: string;
  materialId: string;
  rounds: DebateRound[];
  currentStage: DebateStage;
  completedStages: DebateStage[];
  harvest?: string;
  createdAt: number;
}
```

### 变更说明

- 删除 `DebateMode` 类型（不再区分裁判/对手模式）
- `DebateRound` 增加 `stage` 字段
- `DebateRecord` 删除 `mode` 字段，增加 `currentStage`、`completedStages`、`harvest` 字段
- 复用现有 `debateRecords` localStorage key，不需要新增
