# 素材模块优化设计

**日期**: 2026-05-30
**状态**: 已确认
**范围**: 素材模块内优化（不涉及跨模块联动）

---

## 1. 背景与目标

### 当前问题
- **A. 用户不知道看什么** — 素材太多，缺乏引导，不知道从哪里开始
- **B. 学习体验不够深入** — 讨论太浅，缺乏思维工具，收获感不强
- **D. 界面设计不够吸引人** — 视觉层次、信息架构需要提升

### 设计目标
- 三种浏览模式：随意浏览、每日精选、学习路径
- 辩论式深度学习：用户轮流扮演正反双方
- 阅读材料切合高中作文素材
- 概念地图作为总体布局

### 设计原则
- 简洁干净、文字为主
- Mintlify设计风格
- 信息架构清晰

---

## 2. 功能设计

### 2.1 首页（分层递进式）

**布局结构**：
1. 标题区（简洁）
2. 今日精选（突出展示，减少选择焦虑）
3. 最近学习（快速继续）
4. 功能入口（2×2网格）

**功能入口**：
- 全部素材：18个素材，5个分类
- 学习路径：系统化深入
- 概念地图：15个核心概念
- 随机探索：换个角度看

### 2.2 素材详情页

**布局结构**：
1. 情境描述
2. 核心张力卡片
3. 标签（薄荷绿淡底）
4. 模式选择（自由讨论 / 辩论模式）
5. 阅读材料区

### 2.3 辩论模式（核心交互）

**两种模式**：

**模式A：用户当裁判**
1. 用户写正方论点
2. 用户写反方论点
3. AI点评两边逻辑强度
4. 用户写综合判断

**模式B：AI当对手**
1. 用户选择立场（正/反）
2. 用户写论点
3. AI写对立论点
4. 多轮交锋
5. AI总结双方强弱

**交互设计**：
- 轮次清晰可见（第N轮）
- 当前角色突出（浅绿色指示器）
- 论点区域足够大
- 结束后有综合评估

### 2.4 阅读材料

**内容分类**：
- 哲学观点：可引用的思想家观点
- 现实案例：当代事件、新闻
- 历史典故：经典故事、历史事件
- 数据事实：统计数据、研究结果

**设计特点**：
- 每个素材标注"可直接引用"（标签）
- 提供作文素材使用场景提示
- 内容简洁，展开全文提供细节
- 与辩论流程配合：辩论前/中/后

**数据来源**：
- 知乎热榜API：现实案例、社会讨论
- 哲学专题库（斯坦福哲学百科）：系统的思想家观点
- 维基百科：历史事件、科学事实

### 2.5 学习路径

**按主题**：
- 我与自我
- 我与他人
- 我与世界
- 我与时代
- 我与传统

**按能力**：
- 学会质疑
- 多角度分析
- 逻辑推理
- 概念界定
- 认知冲突

### 2.6 概念地图

- 15个核心概念
- 可视化展示概念间关联
- 点击进入关联素材
- 作为总体布局，帮助用户看到知识网络

## 3. 设计规范（Mintlify风格）

### 3.1 颜色

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色 | #0a0a0a | 黑色，用于标题、主要按钮 |
| 强调色 | #00d4a4 | 薄荷绿，用于活跃状态、CTA |
| 强调色深 | #00b48a | 薄荷绿深色，用于文字 |
| 表面色 | #f7f7f7 | 灰色背景 |
| 表面色软 | #fafafa | 更浅的灰色背景 |
| 边框色 | #e5e5e5 | 1px边框 |
| 边框色软 | #ededed | 更浅的边框 |
| 文字主色 | #0a0a0a | 标题、主要文字 |
| 文字次色 | #3a3a3c | 正文 |
| 文字三色 | #5a5a5c | 次要文字、标签 |
| 文字弱色 | #a8a8aa | 禁用状态 |

### 3.2 标签

- 样式：浅绿底 + 深绿文字
- 背景：`rgba(0, 212, 164, 0.1)`
- 文字：`#00b48a`
- 字体：13px, 500 weight
- 圆角：4px
- 内边距：2px 8px

### 3.3 按钮

**主要按钮**（黑色pill）：
- 背景：#0a0a0a
- 文字：#ffffff
- 圆角：9999px
- 内边距：10px 20px
- 字体：14px, 500 weight

**次要按钮**（边框pill）：
- 背景：transparent
- 边框：1px solid #e5e5e5
- 文字：#5a5a5c
- 圆角：9999px

**角色指示器**（当前角色）：
- 背景：`rgba(0, 212, 164, 0.1)`
- 文字：`#00b48a`
- 圆角：9999px
- 字体：12px, 600 weight

**角色指示器**（非当前角色）：
- 背景：#f7f7f7
- 文字：#5a5a5c
- 圆角：9999px

### 3.4 卡片

- 背景：#ffffff
- 边框：1px solid #e5e5e5
- 圆角：12px
- 内边距：20-24px

### 3.5 输入框

- 边框：1px solid #e5e5e5
- 圆角：8px
- 内边距：12px
- 字体：14px, 1.50行高

### 3.6 排版

**标题**：
- 28px, 600 weight, -0.5px字间距
- 22px, 600 weight, -0.3px字间距
- 18px, 600 weight

**正文**：
- 14px, 400 weight, 1.70行高（情境描述）
- 14px, 400 weight, 1.50行高（一般正文）

**标签文字**：
- 11px, 600 weight, 0.5px字间距, 大写

**小标签**：
- 12px, 500 weight

### 3.7 间距系统

- 基础单位：4px
- 主要增量：8px
- 卡片内边距：20-24px
- 区块间距：24-32px

## 4. 数据架构

### 4.1 素材数据（现有）

```typescript
interface Material {
  id: string;
  category: MaterialCategory;
  title: string;
  situation: string;
  coreTension: string;
  guideQuestions: string[];
  linkedDrills: string[];
  tags: string[];
}
```

### 4.2 阅读材料数据（新增）

```typescript
interface ReadingMaterial {
  id: string;
  materialId: string;
  type: 'philosophy' | 'case' | 'history' | 'data';
  title: string;
  content: string;
  source?: string;
  usageHint: string; // 作文使用场景提示
  quotable: boolean; // 是否可直接引用
}
```

### 4.3 辩论记录数据（新增）

```typescript
interface DebateRecord {
  id: string;
  materialId: string;
  mode: 'judge' | 'opponent';
  rounds: DebateRound[];
  summary?: string; // AI总结
  createdAt: number;
}

interface DebateRound {
  round: number;
  side: 'for' | 'against';
  content: string;
  isUser: boolean;
  timestamp: number;
}
```

### 4.4 学习路径数据（新增）

```typescript
interface LearningPath {
  id: string;
  type: 'theme' | 'ability';
  name: string;
  description: string;
  materialIds: string[];
  order: number;
}
```

## 5. API集成

### 5.1 知乎热榜API

- 用途：获取现实案例、社会讨论
- 调用时机：生成阅读材料时
- 数据处理：提取关键观点、案例背景

### 5.2 哲学专题库（斯坦福哲学百科）

- 用途：获取思想家观点、伦理案例
- 调用时机：生成阅读材料时
- 数据处理：提取核心主张、引用

### 5.3 维基百科API

- 用途：补充历史事件、科学事实
- 调用时机：生成阅读材料时
- 数据处理：提取关键事实、数据

### 5.4 阅读材料生成流程

```
素材主题 → 检索知识库 → 提取关键点 → 结构化 → 生成阅读卡片 → 缓存到本地
```
