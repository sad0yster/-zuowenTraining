# 题库检索功能设计

**日期:** 2026-06-11
**目标:** 为写作模块的题库选择页面添加简洁、专注的检索功能

---

## 1. 设计原则

- **简洁优先** — 默认界面保持简洁，筛选功能按需展开
- **降低选择焦虑** — 减少筛选维度，避免信息过载
- **符合产品调性** — 面向高中生冲刺高分，专注思辨训练

---

## 2. 标签分类方案

### 2.1 主题标签（8个）

| 标签 | 含义 | 示例题目 |
|------|------|----------|
| 科技 | AI、互联网、技术发展 | q1, q20, q27 |

| 自我 | 独立、自由、身份认同 | q26, q46, q47 |
| 时代 | 变革、未来、当下 | q30, q61, q62 |

### 2.2 思辨类型标签（3个）

| 标签 | 含义 |
|------|------|
| 一元 | 单一概念深入 |
| 二元 | 两面思辨 |
| 三元 | 多元关系 |

### 2.3 标签分配规则

每个题目分配：
- 1个主题标签（新增 `theme` 字段）
- 1个思辨类型标签（已有 `speculativeType` 字段，无需修改）

**注意：** 保留现有 `tags` 字段用于其他功能（如推荐算法），但筛选功能只使用 `theme` 和 `speculativeType`。

## 4. 数据结构变更

### 4.1 questions.json

每个题目添加 `theme` 字段：

```json
{
  "id": "q1",
  "text": "...",
  "source": "2024新课标I卷",
  "genre": "argumentative",

  "tags": ["科技与思考", "问题意识", "二元思辨"],
  "theme": "科技"
```

### 4.2 类型定义

```typescript
export type QuestionTheme = 
  | '科技' 
  | '人文' 
  | '社会' 
  | '成长' 
  | '文化' 
  | '价值' 
  | '自我' 
  | '时代';

export interface Question {
  id: string;
  text: string;
  source: string;
  genre: EssayGenre;
  speculativeType: SpeculativeType;
  difficulty: 1 | 2 | 3;

  theme: QuestionTheme;
}
```

## 5. 组件结构

### 5.1 TopicInput.tsx

```typescript
// 状态管理
const [searchText, setSearchText] = useState('');
const [showFilters, setShowFilters] = useState(false);
const [selectedThemes, setSelectedThemes] = useState<QuestionTheme[]>([]);
const [selectedTypes, setSelectedTypes] = useState<SpeculativeType[]>([]);

// 筛选逻辑
const filteredQuestions = useMemo(() => {
  return allQuestions.filter(q => {
    if (searchText && !q.text.includes(searchText) && !q.source.includes(searchText)) return false;
    if (selectedThemes.length > 0 && !selectedThemes.includes(q.theme)) return false;
    if (selectedTypes.length > 0 && !selectedTypes.includes(q.speculativeType)) return false;
    return true;
  });
}, [searchText, selectedThemes, selectedTypes]);

// 切换筛选
const toggleTheme = (theme: QuestionTheme) => {
  setSelectedThemes(prev => 
    prev.includes(theme) ? prev.filter(t => t !== theme) : [...prev, theme]
  );
};

const toggleType = (type: SpeculativeType) => {
  setSelectedTypes(prev => 
    prev.includes(type) ? prev.filter(t => t !== type) : [...prev, type]
  );
};

const clearFilters = () => {
  setSearchText('');
  setSelectedThemes([]);
  setSelectedTypes([]);
};
```

### 5.2 筛选面板 JSX

```jsx
{showFilters && (
  <div className="filter-panel">
    <div className="filter-section">
      <span className="filter-label">主题</span>
      <div className="filter-options">
        {THEMES.map(theme => (
          <button
            key={theme}
            className={`filter-btn ${selectedThemes.includes(theme) ? 'active' : ''}`}
            onClick={() => toggleTheme(theme)}
          >
            {theme}
          </button>
        ))}
      </div>
    </div>
    <div className="filter-section">
      <span className="filter-label">类型</span>
      <div className="filter-options">
        {TYPES.map(type => (
          <button
            key={type}
            className={`filter-btn ${selectedTypes.includes(type) ? 'active' : ''}`}
            onClick={() => toggleType(type)}
          >
            {type === 'single' ? '一元' : type === 'binary' ? '二元' : '三元'}
          </button>
        ))}
      </div>
    </div>
    <button className="clear-filters" onClick={clearFilters}>清空筛选</button>
  </div>
)}
```
