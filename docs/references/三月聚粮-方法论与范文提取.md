## 一、核心方法论

### 1. 矛盾二分法（审题的唯一解法）

**核心理念**：任何作文题的核心都是一个矛盾。找到矛盾，就能找到立意方向。

**操作路径**：

```
拿到题目 → 用"一秒钟法则"提取核心词
    ↓
对核心词做"矛盾二分"：
    是什么 —— 不是什么
    为什么 —— 不为什么
    怎么样 —— 不这样会怎样
    ↓
进步，因为矛盾
```

**实战案例**（2015安徽卷·蝴蝶翅膀）：

题目关键信息：
- 蝴蝶翅膀在显微镜下失去了色彩
- 本是无色的，因特殊的微观结构才呈现色彩

矛盾二分拆解：
- **是什么**：蝴蝶翅膀本来无色，"色彩"是光线+结构的产物
- **不是什么**：色彩不是固有的、不是本质的
- **为什么不**：如果结构被改变，色彩就消失
- **怎么样的视角**：显微镜让我们看到了"真相"——原来美丽的色彩是一种"错觉"

**隐含前提**：
- "失去色彩"暗示色彩是好的——但失去色彩后呈现的结构美，是不是另一种美？
- "惊奇"暗示学生期待色彩是本质的——但自然界很多美都是"关系的产物"

---

### 2. 句模本（思考的框架，不是模板）

**核心理念**：句模本不是套话模板，而是"思考的框架"——你在想和写之间搭的一座桥。

**与模板的区别**：
- 模板："引议联结"，说了等于白说
- 句模本：具体的思维模型和句式，帮你在考场上快速组织论证

**核心框架**：

**（1）立意框架：概念界定 + 关系辨析 + 价值升华**

```
第一层（概念界定）：A是什么？B是什么？
第二层（关系辨析）：A和B是什么关系？因果？条件？并列？递进？
第三层（价值升华）：A和B之上有没有一个更大的问题？
```

**（2）论证框架：主张 → 理由 → 证据 → 推理 → 反驳**

```
主张：我认为……
理由：因为……
证据：比如……（例子要精不要多）
推理：这意味着……（这一步最容易被省略）
反驳：有人可能会说……但我认为……
```

**（3）分论点框架：正—反—合**

```
正：A的合理性——在什么条件下A成立
反：A的局限性——B的价值在哪里
合：A和B之上的统摄概念——不是折中，是升维
```

---

### 3. 审题的一秒钟法则

**核心理念**：拿到任何作文题，用一秒钟圈出最核心的关键词。

**操作步骤**：
1. 删掉所有背景介绍、修饰语、情境描述
2. 只留最核心的"一件事 / 一个人 / 一句话 / 一个观点 / 一幅画"
3. 对这个核心做矛盾二分

**示例**（2022全国甲卷·红楼梦题匾）：

原文很长，删掉所有不重要的：
- "元妃省亲"——删，不需要读过红楼梦
- "匾额题名"——核心：命名/表达
- "直接移用 / 借鉴化用 / 根据情境独创"——核心：三种创新方式

一秒钟核心：**模仿 → 改造 → 创造**，三种关系不是并列，是递进。

---

### 4. 一例万用（一个素材用在多个话题）

**核心理念**：不堆砌素材，把一个素材吃透，用在多个话题中。

**操作方法**：
1. 选一个你最熟悉的素材（人物/事件/故事）
2. 从这个素材中提取多个"维度"——不是事件本身，而是事件可以被解读的角度
3. 每个维度对应一个可能的话题

**示例**：苏轼这个素材可以用于——
- **得与失**：被贬是"失"，写出《赤壁赋》是"得"
- **强与弱**：政治上是弱者，文学上是强者
- **自由与约束**：被贬黄州，行动不自由，但精神最自由
- **坚持与变通**：坚持文学追求，但变通了人生策略
- **孤独与伟大**：孤独的流放者，成就了最伟大的作品

## 四、写作技术提取

### 技术一：概念界定法（立意的起点）

**操作**：拿到题目中的核心词，先回答"是什么"和"不是什么"。

**案例**：
- "平凡"：是一种姿态（主动选择） ≠ 平庸（被动放弃）
- "自由"：想做什么就做什么 ≠ 有能力不做不想做的事
- "止"：节制（老子）/ 达到（大学）/ 退让（孔子）/ 坚持（不到长城非好汉）——同一个字在不同语境下含义完全不同

**关键**：不急于表态，先把概念的边界划清楚。

---

### 技术二：条件分析法（论证的引擎）

**操作**：任何判断都要追问"在什么条件下成立"。

**案例**：
- "坚持就是胜利"——条件：方向正确的前提下。方向错了，坚持就是固执。
- "竞争让人进步"——条件：规则公平的前提下。规则不公平，竞争就是内卷。
- "坦诚才能相遇"——条件：对方有接受坦诚的能力。如果对方没有，坦诚可能是伤害。

**关键**：加条件不是否定论点，是让论点更严密。

---

### 技术三：上位概念法（立意的升维）

**操作**：面对二元对立，不取折中，而是找到统摄二者的更高概念。

**案例**：
- 快 vs 慢 → 统摄于：**人的自主节奏感**（谁在定义我的节奏？）
- 守 vs 变 → 统摄于：**文化基因的稳定性与适应性**
- 个体 vs 群体 → 统摄于：**个体和集体的关系在不同情境下是不同的**（不给固定答案，引导学生发现情境性）

**关键**：升维不是"两者都重要"，是"这两者之上有一个更大的问题"。

---

### 技术四：视角切换法（立意的宽度）

**操作**：同一个话题，用不同视角各写一段，看看能看到什么不一样的东西。

**常用视角**：
- 个体视角 → 结构视角（制度/经济/文化）
- 当下视角 → 历史视角（时间尺度拉长）
- 功能视角 → 意义视角
- 主流视角 → 边缘视角

**案例**：
- "平凡与平庸"，个体视角看是品德问题，结构视角看是社会分配问题——"为什么乡村教师是'平凡而伟大'的？为什么他的收入远低于网红？"
- "自由与约束"，个体视角看是意志问题，制度视角看是法律保障问题——"脱离制度讨论个人自由是空洞的"

---

### 技术五：标题三层次法（命题训练）

**层次一：告知型**——告诉读者我要写什么
- "谈得与失的辩证关系"
- "论技术与时间的关系"

**层次二：表态型**——亮出核心观点
- "得失之间，时间给出答案"
- "我们从未掌控时间，是时间掌控了我们"

**层次三：张力型**——制造认知冲突，让读者一定要往下看
- "所有的失去都在暗中标好了价格"
- "你以为你在管理时间，其实你在被时间管理"

**张力来源**：
- 反转常识（"没有压舱石，船才跑得更快"）
- 制造悬念（"所有的失去都在暗中标好了价格"）
- 挑战共识（"别再歌颂平凡了，那是一种麻醉"）
- 口语化挑衅（"你连竞争什么都搞不清楚，就别争了"）

---

### 技术六：论证漏洞检测法（论证链训练）

**常见漏洞类型**：

| 漏洞 | 表现 | 检测问题 |
|------|------|---------|
| 以例代证 | 举两个例子就下结论 | "例子能代表普遍情况吗？" |
| 因果跳跃 | A发生在B之前，就说是A导致了B | "中间有没有其他因素？" |
| 偷换概念 | 论证过程中悄悄换了关键词的含义 | "你第一段说的'自由'和第三段是同一个意思吗？" |
| 循环论证 | 用结论证明结论 | "有没有独立于结论本身的证据？" |
| 以偏概全 | 从少数例子推出普遍规律 | "有没有反例？反例说明了什么？" |
| 诉诸权威 | "某某名人说过……所以是对的" | "为什么他说的就是对的？" |
| 修辞替代理证 | 用漂亮的句子掩盖推理的缺失 | "如果去掉修辞，剩下的推理步骤是什么？" |

---

### 技术七：意象闭环法（语言的收束）

**操作**：开头埋一个意象/比喻，结尾让它重新出现，但带上全文思考后的新含义。

**案例**：
- 开头"行旅于人生大道的我们"，结尾"人生如逆旅，你我皆行人"——但此时"行人"已有了新的理解
- 开头"跌宕风流总性灵，眼底烟霞付笔端"，结尾"从浴火于跌宕的烟霞中走出"——首尾呼应，意境升华

## 五、素材运用原则

### 1. 素材不是装饰品，是论据

**错误用法**："像屈原那样爱国"——说了等于没说
**正确用法**："屈原在楚国灭亡后投江殉国，他的选择提出了一个至今未解的命题：当共同体背弃你珍视的价值时，个体的忠诚应该给共同体，还是给价值本身？"

### 2. 素材升维的四个层次

| 层次 | 方式 | 示例（屈原） |
|------|------|------------|
| 平庸 | 堆名字 | "像屈原那样爱国" |
| 一般 | 讲事迹 | "屈原在楚国灭亡后投江殉国" |
| 较好 | 析因果 | "屈原的悲剧是士人在大一统浪潮中失去独立性的缩影" |
| 高级 | 框架化 | "屈原的选择提出了一个命题：当共同体背弃你珍视的价值时，个体的忠诚应该给谁？" |

### 3. 一例万用的核心

不是把同一个例子换汤不换药地塞进不同话题，而是从同一个素材中挖掘出多个维度——每个维度对应一个不同的话题。苏轼可以用于"得失"、"强弱"、"自由"、"坚持"、"孤独"，关键是每次用他素材中的不同侧面。

### 4. 素材来源的多样性

好的素材搭配应该是：
- 一古一今（时间纵深）
- 一中一外（文化宽度）
- 一虚一实（文学+现实）
- 一个个体 + 一个群体（层次差异）

## 六、上海卷思辨特色（阿洛老师体系）

### 核心方法：多层思辨推进

上海卷作文的特点是**层次推进**——不是写一个论点然后堆材料，而是层层深入，每一层比上一层更深。

**层级结构示例**（6-16层思辨）：

| 层 | 做什么 | 用什么工具 |
|----|--------|----------|
| 1-2 | 澄清概念 | "这个词到底指什么？" |
| 3-4 | 条件分析 | "在什么条件下成立？" |
| 5-6 | 关系辨析 | "A和B之间是什么关系？" |
| 7-8 | 视角切换 | "换个角度看呢？" |
| 9-10 | 框架反思 | "我们用什么框架在看这个问题？" |
| 11-12 | 元认知 | "判断标准本身是谁定的？" |
| 13-16 | 哲学升维 | 引入概念框架——但用日常语言表达 |

### 关键原则

- 每次只推一层，不跳跃
- 层层推进不等于面面俱到——选最有力的2-3层深入
- 最高层是质疑题目的前提——"这个题目的问题本身有没有问题？"

## 七、应试避坑清单

### 审题避坑

1. **不要只看表面关键词**——删掉所有修饰语，找最核心的矛盾
2. **不要急于表态**——先把概念界定清楚再选边
3. **不要忽略隐含前提**——题目中"不言自明"的假设，往往是立意的突破口

### 立意避坑

1. **不要选"大家都会想到"的立意**——第一反应通常是平庸的
2. **不要取折中**——"两者都重要"是正确的废话
3. **不要把"辩证"等同于"两面都说到"**——辩证是找到统摄二者的更高逻辑

### 论证避坑

1. **不要以例代证**——例子不是论证，推理步骤才是
2. **不要修辞替代理证**——漂亮的句子不等于严密的逻辑
3. **不要跳过推理步骤**——论据和结论之间必须有"这意味着……"

### 结构避坑

1. **不要"大傻二傻三傻"式分论点**——三个分论点说同一件事的三个版本
2. **不要开头结尾背模板**——阅卷老师一眼看穿
3. **不要忽略首尾呼应**——开头的意象/比喻在结尾重新出现，带上全文的重量
