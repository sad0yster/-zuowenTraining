### Task 1: 类型定义

**Modify:** `src/types/index.ts`

```typescript
// 训练单元专属题目接口
export interface ExaminingDrill {
  id: string;
  topic: string;
  source: string;
  hiddenPremises: string[];
  coreConcepts: string[];
  angleHints: string[];
}

export interface ThesisDrill {
  id: string;
  topic: string;
  source: string;
  mediocreThesis: string;
  betterThesis: string;
  advancedThesis: string;

export interface TitlingDrill {
  id: string;
  thesis: string;
  topic: string;
  notifyTitle: string;
  assertiveTitle: string;
  tensionTitle: string;
  whyTension: string;
}

export interface ReasoningDrill {
  id: string;
  topic: string;
  source: string;
  claim: string;
  draftArgument: string;
  weakPoints: string[];

}

export interface PerspectiveDrill {
  id: string;
  topic: string;
  source: string;
  defaultAngle: string;
  alternateAngles: string[];
  angleInsight: string[];
}

// 统一 drill 数据联合类型
export type DrillItem =
  | ExaminingDrill
  | ThesisDrill
  | TitlingDrill
  | ReasoningDrill
  | PerspectiveDrill;
```

### Task 4: 重构 TrainingUnit

**Modify:** `src/components/TrainingUnit.tsx`

将 steps 从 `topic-select | practice | feedback` 改为 `guide | select | practice | feedback`。

- `guide` 步骤：渲染 DrillGuide
- `select` 步骤：加载该方向专属 JSON，渲染选题列表（显示 topic + source）
- `practice` 步骤：根据 drillType 显示不同 placeholder 提示
- `feedback` 步骤：不变

修改 `handleSelectTopic` 为接收完整 drill item（而非纯文本），传递结构化数据给 AI。
