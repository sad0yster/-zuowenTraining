# 高分深度作文写作体系

> 综合国家玮、李智勇、阿洛老师、清北王淏然、教书琐记等名师教学体系，
> 融合哲学/社会学概念框架，面向 55→满分 高分段学生的系统化写作方法论。

---

## 第一篇：评分体系——知道阅卷人看什么

### 一、基础等级（40 分）——五根柱子

基础等级含 **内容项（20分）** 和 **表达项（20分）**，共同考察五个维度，任一失守直接掉到三等以下。

#### 1.1 审题——守门员

不跑题是及格线本身。跑了题 = 内容直接判四等（0-5分），全文崩塌。

四个等级标准：
- 一等（20-16分）：**切合**题意
- 二等（15-11分）：**符合**题意
- 三等（10-6分）：**基本符合**题意
- 四等（5-0分）：**偏离**题意

审题的两个层次：
- **审准**：不跑题，读懂材料表层信息——这是底线
- **审高**：从材料中看到别人看不到的立意角度——这是高分入口

#### 1.2 结构——骨架

必须完整：开头（引论）→ 主体（本论，至少2-3个论证段）→ 结尾（结论）。

- 一等：结构**严谨**
- 二等：结构**完整**
- 三等：结构**基本完整**
- 四等：结构**混乱**

关键规则：表达项原则上不跨等给分。内容判三等，表达不能在一等。

#### 1.3 文体——身份证明

议论文必须像议论文：有论点、有论据、有论证过程。写成记叙文/散文/流水账 = 表达直接判四等。

#### 1.4 语言——地基

句子通顺无语病，字迹能辨认。可以不出彩，但不能崩。

#### 1.5 内容——血肉

有真实论据支撑、论据能佐证观点。论据编造或与论点无关直接扣分。

---

### 二、发展等级（20 分）——决定上限

发展等级含 4 项 16 个评分点，**不求全面，以突出点按等评分**。只要某一两个点特别出彩，就能拿到发展等级满分。

#### 2.1 深刻

- 透过现象看本质
- 揭示事物内在的因果关系
- 观点具有启发作用

#### 2.2 丰富

- 材料丰富
- 论据充足
- 形象丰满
- 意境深远

#### 2.3 有文采

- 用词贴切
- 句式灵活
- 善于运用修辞手法
- 文句有表现力

#### 2.4 有创意

- 见解新颖
- 材料新鲜
- 构思精巧
- 推理想象有独到之处
- 有个性特征

**关键规则**：发展等级分不能跨越基础等级的得分等级。基础等级判三等，发展等级不可能判一等。意思是——思想再深刻，审题跑了全白费。

---

### 三、扣分项

- 缺标题：扣 2 分
- 错别字：每错 1 字扣 1 分，重复不计，扣满 5 分为止
- 字数不足：每少 50 字扣 1 分
- 标点错误：3 处以上酌情扣分

## 第二篇：审题立意体系

### 一、国家玮「主题四问法」

从思维本质上避免跑题，同时打开立意空间：

1. **一问——材料在说什么？（现象层）**：准确复述材料内容，确认没有误读
2. **二问——材料的核心矛盾/问题是什么？（本质层）**：从现象中提取关键概念或概念对
3. **三问——我对此的立场/判断是什么？（观点层）**：形成自己的明确主张
4. **四问——我的观点能否给阅卷人提供"有趣的灵魂"？（深度层）**：追问自己的观点是否独特

### 二、多向度思维 vs 单向度思维（国家玮）

**单向度思维**：看见一个材料只想一个角度。这是大多数学生的思维习惯。

**多向度思维**：从不同维度审视同一材料：
- **主体维度**：谁在行动？谁在说话？换一个主体视角会怎样？
- **背景维度**：在什么情境下发生的？换个时代/文化/阶层背景呢？
- **动态过程维度**：事物如何发展变化？放到更长的时空尺度看呢？

### 三、立意层次模型

同一道题，三层立意天差地别：

| 层次 | 特征 | 示例（以「坚持」为题） |
|------|------|------------|
| **平庸立意** | 感性描述、鸡汤式表态 | "坚持就是胜利""只要坚持就能成功" |
| **较好立意** | 辩证分析、条件限制 | "坚持不是盲目固执，而是方向正确后的耐力" |
| **高级立意** | 概念框架升维、现象学洞察 | "坚持不是时间的累积，而是人在每次放弃的边缘重新确认自己的选择——每一次选择继续，都是对'我是谁'的重新回答" |

### 四、李智勇「升维作文法」核心

**核心理念**：援引跨学科认知框架来观照作文题目，在立意、表达、结构三个层面实现升维，对平庸立意形成"降维打击"。

**24 招精选**（适用于议论文部分）：

审题篇：
- 审题怎么才算审得准？——回到材料关键词，不做过度联想
- 审题怎么才能审得高？——从材料中提取可升维的哲学母题
- 如何避开大家都会想到的立意？——先列出三个最常见的立意，然后扔掉它们

立意篇：
- 两难型材料怎么腾挪？——不在两极之间取折中，而是找到统摄二元的上位概念
- 如何从一件事中看出象征意义？——把具体事件还原为人类普遍处境
- 什么样的认知显得成熟？——能同时容纳两种对立观点而不急于消灭任一方

表达篇：
- 宏大命题怎么写不空？——找到一个具体的"人"作为载体
- 如何把宏大转化为生动形象？——用场景和细节替代抽象概念堆砌
- 观点无法翻新，如何实现表达翻新？——换一个隐喻系统重新讲述同一个道理

## 第三篇：概念升维——用概念框架打开立意空间

> 核心原则：不讲理论体系，而是用日常生活/社会切片投射概念。
> 让学生在具体情境中**体验到**更高阶的视角，而不是**学到**某个学术概念。
>
> **关键认知**：可用的概念框架是无穷的——哲学、社会学、心理学、经济学、人类学、历史学、政治哲学……任何学科都提供观察世界的透镜。**不预先框定概念库，而是让 AI 根据每个具体作文题动态匹配最合适的概念框架。** 下面展示的是方法，不是课程大纲。

### 一、核心操作：怎么把概念变成立意

面对任何一个作文题，升维的操作路径是：

```
审出核心概念 → 找到可碰撞的概念框架 → 用生活切片建立连接 → 形成高级立意
```

**四个步骤**：

1. **识别母题**：这道题背后是人跟什么的关系？自我与他人？个体与社会？自由与秩序？传统与创新？表象与本质？
2. **动态匹配概念**：针对这个具体母题，什么概念框架能提供新的观察角度？——不同题目适配不同概念，不预设、不硬套
3. **投射到生活**：不用学术语言解释概念，而是抛出一个学生能感知的生活情境，让他们在情境中**体验到**这个视角
4. **回到立意**：带上这副新眼镜，重新看题目——原来没看到的角度现在清晰了

### 二、概念导入的通用模式

任何概念都可以通过以下结构传递：

| 步骤 | 做什么 | 示例（以「消费社会的符号逻辑」为例） |
|------|--------|------|
| **破冰** | 一个身边的生活切片，制造认知冲突 | "一双 200 元和 2000 元的球鞋，走路功能上几乎没差别。那 1800 元买的是什么？" |
| **点破** | 一句话揭示切片背后的概念内核 | "你可能不是在买鞋——你是在买一个信号，告诉别人你是哪类人。" |
| **迁移** | 把概念引回作文题目 | "回到你写的这道题——你讨论的'物质追求'，有没有可能不只是对东西的渴望，还包括对'身份标签'的渴望？" |
| **追问** | 推动进一步思考 | "如果消费行为里有大量'表演'成分，那么'真实的自我'到底在哪里？" |

### 三、概念应用的通用思维工具

不依赖特定概念，而是掌握几个通用的思维操作，适用于任何概念框架：

| 操作 | 说明 | 在任何题目中都可以问 |
|------|------|------------|
| **视角转化** | 换一个主体/时代/文化背景看同一件事 | "如果换成一个唐朝人看这件事，他在意什么？" |
| **概念辨析** | 区分容易混淆的概念对，在差异中凸显本质 | "你说的自由，是'想做什么就做什么'还是'有能力不做不想做的事'？" |
| **条件化** | 不简单说对或错，而是分析在什么条件下成立 | "在什么样的环境下，这个观点是成立的？什么时候它失效？" |
| **反例测试** | 主动找反例，检验论证是否严密 | "有没有一个情况，能证明你的结论是错的？如果有，这说明什么？" |
| **时间拉伸** | 把问题放到更大的时间尺度中看 | "这个选择，五十年后回头看还重要吗？如果是一百年呢？" |
| **层级切换** | 个体→群体→制度→文明，在不同层级之间跳跃 | "这件事放在个人层面是道德选择，放在制度层面变成了什么？" |

### 四、概念辨析法——界定你真正在讨论什么

**核心操作**：不急于论证，先搞清楚核心概念到底是什么意思。

**三步法**：

1. **是……不是……**：平凡不是平庸。前者是姿态的谦逊，后者是追求的放弃。
2. **加条件**：在什么情况下这个结论成立？在什么情况下不成立？
3. **定边界**：我讨论的限于哪个范围？

**常被混淆的概念对**：平凡vs平庸、自信vs自负、自由vs放任、平等vs公平、传统vs保守、竞争vs内卷、个性vs任性……无穷无尽，不同题目涉及不同概念对。

### 五、二元思辨——超越非黑即白

#### 常见二元关系类型

| 关系类型 | 示例 | 写作策略 |
|----------|------|----------|
| **对立转化** | 强与弱、苦与乐、危与机 | 指出对立面在何种条件下可以转化 |
| **并列共存** | 借鉴与独创、德与才 | 各述其理，再论融合的必要 |
| **条件关系** | 守界与跨界（只有深研一域，才有跨界的能力） | 论证一方是另一方的前提 |
| **递进关系** | 认知→理解→行动 | 不是并列讨论，而是层层深入 |

#### 关键策略：上位概念统摄

不取折中，而是找到统摄二元的上位概念：

- "守"与"变" → 统摄于 **文化基因的稳定性与适应性**
- "俯视"与"仰视" → 统摄于 **自我认知的辩证法**
- "快"与"慢" → 统摄于 **人的自主节奏感**

#### 思辨技法六式

1. **加条件**：观点并非在一切情况下成立。"大多数情况下……""在……条件下……"
2. **限对象**：限定观点适用的范围。"对于……来说……"
3. **留余地**：避免绝对化。"……不一定……""只有……才可能……"
4. **搞假设**：预设反方观点进行驳论。"退一步讲，假如……"
5. **做界定**：对核心概念进行边界界定。"这里所说的……，不是……，而是……"
6. **然对方**：先承认对方的合理之处。"诚然……但是……"

## 第四篇：论证体系

### 一、论证的本质

论证 = 主张 + 理由 + 证据 + 推理链 + 应对反驳

**常见论证误区**：
- **以例代证**：举一个例子就认为观点成立
- **以情代理**：用情感渲染替代逻辑推导
- **偷换概念**：论证过程中悄悄换了论点的含义
- **循环论证**：用结论本身来证明结论
- **稻草人**：歪曲对方观点然后攻击这个假靶子
- **以偏概全**：从少数例子推出普遍结论

### 二、论证结构模式

#### 模式一：纵深递进（适合思想深度类题目）

```
现象呈现 → 原因分析 → 本质追问 → 对策建构 → 意义升华
```

#### 模式二：正反合（适合二元思辨类题目）

```
正面论证(A的合理性) → 反面论证(A的局限性 / B的价值) → 合(找到统摄A和B的更高逻辑)
```

#### 模式三：多维展开（适合宏大主题）

```
角度一(个体层面) → 角度二(社会/历史层面) → 角度三(哲学/文明层面)
```

### 三、分论点展开的六个角度

不面面俱到，选 3-4 个角度即可：

1. **明是非**：一分为二看问题，对立统一
2. **揭本质**：透过现象看本质，挖掘规律
3. **谈意义**：分析积极和消极意义，正反对照
4. **析原因**：追本溯源，探究因果逻辑链条
5. **提方法**：提出解决问题的具体路径
6. **论影响**：拓展延伸，论述深远影响

### 四、核心论证段落的结构

```
段落观点句 → 阐释句(为什么这么说) → 论据句(事例/数据/引用) → 分析句(这个论据如何证明观点) → 回扣句(与本段观点和全文中心的关系)
```

**关键**：分析句而非论据句，才是一段论证的核心。堆例子不等于论证。

## 第五篇：标题与命题

### 一、标题的本质

标题是立意的浓缩版。一个好的标题让阅卷人在 5 秒内判断：这个人有自己的想法。

### 二、标题的三个层次

| 层次 | 特征 | 示例 |
|------|------|------|
| **告知型** | 告诉读者我要写什么 | "论坚持""谈自由" |
| **表态型** | 亮出核心观点 | "坚持的真谛在于选择""自由是责任而非任性" |
| **张力型** | 标题本身就制造认知冲突，让人想读 | "每一次坚持，都是一次重新选择""你是自由的吗？先问问你的欲望" |

### 三、标题自检三问

1. 这个标题暗示读者什么期待？
2. 我的正文能不能兑现这个期待？
3. 这个标题是只有我能写，还是随便谁都能用？（越是后者，标题越平庸）

## 第六篇：素材体系

### 一、素材的本质

素材不是装饰品，是论据。好的素材 = 有细节 + 能与观点形成精确对应关系。

### 二、素材的四个来源维度

| 维度 | 说明 | 示例 |
|------|------|------|
| **个人经验** | 真实的生活体验，细节最丰富 | 观察到的一个场景、一次对话、一个瞬间 |
| **社会现象** | 当下发生的事件，最具时代感 | 社会热点、文化现象、代际冲突 |
| **历史文化** | 人类文明积累，最具纵深 | 历史事件、思想传统、经典文本 |
| **跨学科知识** | 哲学/社会学/经济学/心理学，最具分析力 | 概念框架、理论工具、思维模型 |

### 三、素材与观点的"对版"原则

不堆砌素材，选最能精确支撑当前论点的素材。提问：
- 这个素材真的在证明我的观点吗？还是只是"有点关系"？
- 如果换成反方，能不能用同一个素材支持相反的观点？（如果是，说明素材没有论证力）

### 四、素材升维

同一个素材，不同层次的使用方式天差地别：

| 层次 | 方式 | 示例（以「屈原」为例） |
|------|------|------------|
| **平庸** | 堆名字 | "像屈原那样爱国" |
| **一般** | 讲事迹 | "屈原在楚国灭亡后投江殉国" |
| **较好** | 析因果 | "屈原的悲剧不仅是个人的忠诚，也是士人在大一统浪潮中失去独立性的缩影" |
| **高级** | 框架化 | "屈原的选择提出一个至今未解的命题：当共同体背弃你珍视的价值时，个体的忠诚应该给予共同体，还是给予价值本身？" |

## 第七篇：名师体系对照

### 一、五大名师核心方法论

| 名师 | 核心命题 | 最突出的方法论 | 对本产品的启示 |
|------|---------|---------------|--------------|
| **国家玮** | 改变思想方法而非授套路 | 主题四问法、多向度思维、轴-辐条结构、"有趣的灵魂" | 审题从思维底层入手，立意追求独特性 |
| **李智勇** | 升维→降维打击 | 跨学科框架升维、24招分模块、55篇范文拆解 | 用哲学/社科概念框架替代经验描述 |
| **阿洛老师** | 超越套路的深度思辨 | 绝杀阵法、8-16层思辨推进、上海卷思辨体系 | 思辨有层级可循，可以逐层递进训练 |
| **清北王淏然** | 理科思维教语文 | 论证武器库、思辨结构模板、素材分主题体系 | 方法论结构化、可操作、可复制 |
| **教书琐记** | 语文的外延是生活 | 课堂实录、文本细读、在人文深度与应试之间找平衡 | 不割裂应试与素养，"深刻的作文来自深刻的人" |

### 二、作文学习的五个阶段

对应各名师的体系重叠部分，可归纳为：

```
第一阶段：站稳脚跟（基础等级不出错）
  → 审题准、结构全、文体对、语言通
  → 对应国家玮「基础等级逐条攻破」

第二阶段：言之有物（有论据、有论证）
  → 素材积累、论证段落结构、论据与观点对接
  → 对应清北王淏然「论证武器库」、国家玮「素材密码」

  → 分论点展开、段落间逻辑、全文节奏
  → 对应国家玮「结构密码」「轴-辐条」、李智勇「表达升维」

第四阶段：言之有思（立意深度与思辨力）

  → 对应阿洛老师「14-16层思辨」、国家玮「立意密码」、李智勇「立意升维」

第五阶段：言之有我（形成写作个性）
  → 找到自己的思考偏好和表达风格
  → 对应教书琐记、国家玮「有趣的灵魂」
```

## 第九篇：底层设计原则

1. **不讲概念，给情境**：不说"功利主义"，而是给一个电车难题让学生表态
2. **不评价人，只追问论证**：不说"你这个立意太浅"，而是问"如果换个角度看呢？"
3. **不替代思考，只暴露盲区**：不给标准答案，而是揭示学生自己论证中的跳跃和遗漏
4. **不预设素养门槛**：用日常语言讨论深刻问题，不说学术黑话
5. **训练即考试，考试即训练**：训练内容直接对应评分标准，每次训练都让学生看到和满分的距离
