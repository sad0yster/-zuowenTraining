# 高分作文训练 - 需求文档

## 1. 项目概述

一个帮助学生写出高分作文的在线训练工具。聚焦考场作文评分标准，通过拆解高分范文 + 逐项刻意练习 + AI 按评分标准反馈，让写作提分可量化。

## 2. 目标用户

- 初高中备考学生，希望作文稳定在 48+/50+/60+ 分数段

## 3. 核心功能

### 3.1 高分拆解
- 展示一篇高分范文，标注得分点（审题精准、结构清晰、立意深刻、语言出彩）
- 每项得分点可展开看具体写法分析
- 支持按文体筛选（记叙文、议论文）

### 3.2 单项训练
不写整篇，只练一个得分点：
- **审题训练**：给题目，练立意角度，防止跑题
- **结构训练**：给提纲搭框架（开头-主体-结尾的黄金结构）
- **段落训练**：针对主体段落，练论点+论据+分析
- **语言训练**：句式升级、修辞运用、词汇替换

### 3.3 AI 批改
按考场评分标准反馈，不泛泛而谈：
- 分维度打分（内容 20 + 语言 20 + 结构 20 + 卷面/文面 10，或自定义满分）
- 逐段精批：标出得分句和扣分点，给出具体改写建议
- 生成修改对照版（原文 → 升格文）

### 3.4 范文库
- 精选考场高分范文，每篇附命题分析和得分拆解
- 按文体、主题、分数段筛选

## 4. 页面结构

```
首页（开始训练 / 浏览范文）
├── 高分拆解页
├── 单项训练页
│   ├── 审题
│   ├── 结构
│   ├── 段落
│   └── 语言
├── 写作台 → 批改结果页
└── 范文库
```

## 5. 技术方案

| 层级 | 选型 |
|------|------|
| 前端 | React + TypeScript |
| AI 批改 | 大模型 API，搭配评分 prompt |
| 数据 | 范文和题目存 JSON / 本地文件，无需数据库 |

## 6. 开发顺序

1. 范文库 + 高分拆解展示
2. 写作台 + AI 批改（核心闭环）
3. 单项训练模块
