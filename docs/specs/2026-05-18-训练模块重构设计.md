# 训练模块重构设计

> 日期：2026-05-18

## 问题

当前训练模块三个根本缺陷：

1. **5个训练方向共用同一个题库** — 审题拆解、立意突破、命题训练、论证链、视角切换各自需要不同结构的题目/素材，共用通用题库导致练习无针对性
2. **没有前置引导** — 学生点进训练单元直接看到题目列表，不知道"我在练什么"、"为什么值得练"、"练完会怎样"
3. **题目与训练方向不匹配** — 命题训练需要的是一个已确立的立意让学生拟标题，不是一道原始作文题；论证链需要的是一段待检验的论证草稿，不是原始题目

## 设计目标

每个训练方向有自己专属的题目结构、前置引导、30秒微示例。学生进入训练单元后先理解"我在做什么"，再开始练习。

## 数据模型

每个训练方向一个 JSON 文件，放在 `src/data/drills/` 目录下。

### examining.json — 审题拆解

```typescript
interface ExaminingDrill {
  id: string;
  topic: string;           // 完整作文题
  source: string;          // 来源（真题/模考/原创）
  hiddenPremises: string[]; // 隐含前提（教练参考用）
  coreConcepts: string[];  // 核心概念（教练参考用）
  angleHints: string[];    // 可探索的立意方向（教练参考用）
}
```

### thesis.json — 立意突破

```typescript
interface ThesisDrill {
  id: string;
  topic: string;           // 作文题
  source: string;
  mediocreThesis: string;  // 平庸立意
  betterThesis: string;    // 较好立意
  advancedThesis: string;  // 高级立意
  whyAdvanced: string;     // 高级立意为什么更好（教练参考用）
}
```

### titling.json — 命题训练

```typescript
interface TitlingDrill {
  id: string;
  thesis: string;          // 已确立的立意
  topic: string;           // 对应作文题
  notifyTitle: string;     // 告知型标题（告诉读者我要写什么）
  assertiveTitle: string;  // 表态型标题（亮出核心观点）
  tensionTitle: string;    // 张力型标题（制造认知冲突，引发阅读欲）
  whyTension: string;      // 张力型标题为什么更有力（教练参考用）
}
```

### reasoning.json — 论证链

```typescript
interface ReasoningDrill {
  id: string;
  topic: string;
  source: string;
  claim: string;           // 待检验的论点
  draftArgument: string;   // 一段待检测的论证草稿（有具体漏洞）
  weakPoints: string[];    // 薄弱环节（教练参考用）
  repairSuggestion: string; // 修复方向（教练参考用）
}
```

### perspective.json — 视角切换

```typescript
interface PerspectiveDrill {
  id: string;
  topic: string;
  source: string;
  defaultAngle: string;    // 大多数学生会用的视角
  alternateAngles: string[]; // 可切换的其他视角
  angleInsight: string[];  // 每个视角带来的不同洞察（教练参考用）
}
```

## UX 流程

```
点击训练单元卡片
       ↓
   引导页（前置说明 + 30秒微示例）
       ↓
   选题列表（该方向专属题目）
       ↓
   练习区（学生输入）
       ↓
   反馈对话（AI 教练多轮对话）
       ↓
   保存记录 → 返回
```

### 引导页结构

每个训练单元的引导页包含三个板块：

**板块一：训练内容**
一句话说明这个训练的具体动作。

**板块二：作为训练内容的副标题**
一句话价值锚点——这个能力缺失会导致什么后果。

**板块三：快速感受（30秒微示例）**
用一道题的片段展示"这个训练做完是什么感觉"。不让学生操作，只让看。看完后点"开始练习"进入正式流程。

### 引导页具体内容

| 训练单元 | 你在做什么 | 为什么值得练 |
|---------|-----------|------------|
| 审题拆解 | 给一道作文题，拆出核心概念、隐含前提、可立意方向 | 审题偏了全篇白写。帮你在动笔前看到大多数人看不到的角度 |
| 立意突破 | 你先想一个立意，我帮你看层次，然后引导你往上走 | 48分和55分的差距不在文笔，在立意层次 |
| 命题训练 | 给你一个确立好的立意，你来拟标题 | 阅卷老师5秒看标题判断你有没有想法 |
| 论证链 | 给你论点+论证草稿，逐环检测推理链 | 论证是链条，一环断了全链废 |
| 视角切换 | 同一话题，先用你习惯的视角写，再换视角写 | 你的观点不缺，缺的是"别人想不到的角度" |

## AI Prompt 调整

DRILL_PROMPTS（五个训练方向的系统 prompt）需要更新，以匹配新的数据结构：

- **examining prompt**：参考 `hiddenPremises`、`coreConcepts`、`angleHints` 引导学生拆解
- **thesis prompt**：参考 `mediocreThesis`→`betterThesis`→`advancedThesis` 展示层次差异，用 `whyAdvanced` 解释为什么更高
- **titling prompt**：参考 `notifyTitle`→`assertiveTitle`→`tensionTitle` 展示标题层次
- **reasoning prompt**：参考 `draftArgument`、`weakPoints`、`repairSuggestion` 引导逐环检测
- **perspective prompt**：参考 `defaultAngle`、`alternateAngles`、`angleInsight` 引导视角切换
