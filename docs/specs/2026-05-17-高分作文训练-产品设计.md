# 高分作文训练 — 产品设计规格书

> 日期：2026-05-17 | 状态：待实现

---

## 1. 产品定位

**一句话**：以哲学和社会科学为内核的思辨写作教练——不教套路模板，教学生像哲学家一样提问、像社会学家一样分析，让高分成为思想深度的自然产物。

**靶心用户**：高分段中学生（55→满分），不愿背范文，想真正写出有思考深度的文章。

**使用场景**：课后自主练习，单次 10-20 分钟。

**核心理念**：作文差的根不在文笔，在思考。学生需掌握三样东西——逻辑工具、多元视角、元认知。

---

## 2. 核心差异

| | 现有产品 | 本产品 |
|------|---------|------|
| 训练对象 | 写作技巧 | 思维能力 |
| AI 角色 | 阅卷老师（评判者） | 思辨教练（引导者） |
| 反馈方式 | "这里不好，改成这样" | "你的前提成立吗？换个角度呢？" |
| 训练方式 | 写整篇 → 等批改 | 素材激发 → 拆解练习 → 整篇实战 → 成长可视化 |
| 概念传递 | 不涉及 | 用生活切片投射概念，不讲学术体系 |
| 自适应 | 无 | 根据学生思维表现动态调整引导强度 |

---

## 3. 功能模块

### 模块一：思辨素材（思想起搏器）

用真实、有趣、有争议的内容激发思考。三类素材：哲学讨论、社会事件、文化观念。

**交互模式**：阅读素材 → 表态 → AI 追问 → 讨论收束 → 可跳转相关训练

**内容结构**（每条）：情境呈现（≤300字）+ 核心张力 + AI 引导问题方向

**分类维度**：我与他人 / 我与世界 / 我与时代 / 我与传统 / 我与自我

### 模块二：思辨练习场（刻意练习）

五个训练单元，每次 5-10 分钟：

| 单元 | 训练目标 | AI 行为 |
|------|---------|--------|
| 审题拆解 | 拆关键概念、找隐含前提、列多向立意 | 判断切题，引导触及未达角度 |
| 立意突破 | 平庸→较好→高级立意对比升维 | 展示层次差异，动态匹配概念框架 |
| 命题训练 | 拟多层级标题并自评 | 追问标题暗示的期待、正文能否兑现 |
| 论证链 | 理由→证据→推理→反驳逐环检测 | 识别跳跃、无关、以偏概全 |
| 视角切换 | 同一主题不同框架各写一段 | 引导视角间切换，拉伸思维肌肉 |

### 模块三：自由写作台（整篇实战）

三阶段：写前对话式审题 → 写中独立写作（按需介入）→ 写后对话式复盘（先自评再对照 AI 观察）

### 模块四：我的成长（元认知）

- 思维快照：立意原创性、论证严密性、视角多元度等维度
- 周期性思维报告：反复踩坑、已内化概念、薄弱项
- 训练足迹：各单元投入分布、历史作文

### 模块间跳转

素材→训练（一键）、训练→写作（实战）、写作→训练（补弱）、写作→成长（复盘）、成长→素材/训练（推荐）

## 4. AI 教练行为

### 自适应强度

| 强度 | 触发条件 | 行为 |
|------|---------|------|
| 高扶持 | 审题跑偏、论证崩坏、学生卡住 | 给方向、给脚手架 |
| 中引导 | 方向对但深度不够 | 追问、制造认知冲突 |
| 低介入 | 思维质量已高 | 挑战、放手让学生自评 |

### 三种交互模式

- **追问**：向学生论证的缝隙插问题
- **并置**：给出另一视角让学生自己比较
- **示范**：只在完全卡住时，给参照系不代替判断

### 永远不做

不直接给分（评分仅作为阶段性总结）、不代写、不评价人格、不预设标准立意

### 必须做

追问指向具体内容、先确认再回应、对话结束做三句话内小结

## 5. 内容系统

| 内容库 | 起步规模 | 目标规模 | 说明 |
|--------|---------|---------|------|
| 思辨素材库 | 50-80 条 | 100-200 条 | 专家精选，每条含情境+张力+问题方向 |
| 题库 | 10-20 道 (MVP) | 150-200 道 | 高考真题+模拟题+原创，标记文体/思辨类型/难度 |
| 范文库 | 0 (MVP 不包含) | 50-80 篇 | 附命题分析+得分标注+立意层级分析 |

---

## 6. 页面结构

```
底部 Tab：素材 | 训练 | 写作 | 我的

素材页：分类横向滑动 + 素材卡片瀑布流 → 详情页（情境+对话区）
训练页：五单元卡片 + 最近记录 → 单元内（选题→练习→AI反馈）
写作页：题目输入 → 写前对话（可折叠）→ 编辑器 + 浮动「问教练」→ 复盘对话
我的页：思维快照雷达图 + 成长趋势 + 训练足迹 + 历史作文
```

首页 = 进度快照 + 今日推荐素材 + 最近训练概览

## 7. 技术方案

| 层级 | 选型 | 说明 |
|------|------|------|
| 前端 | React + TypeScript | — |
| AI | 通用大模型 API + 分层 Prompt | 渐进式：先 Prompt 工程验证，积累数据后微调 |

| Prompt 架构 | 三层：角色层 + 场景层 + 题目层 | 可组合、可版本化、可 A/B 测试 |

## 8. 开发阶段

### 阶段一：核心闭环（MVP）
- 模块三（自由写作台）完整流程
- 最小题库（10-20 题）
- 写前引导 + 写后复盘 prompt
- 本地 JSON 存储
- 单页，不做 Tab

### 阶段二：训练体系
- 模块二（五个训练单元）
- 模块四基础版（思维快照 + 训练足迹）
- 底部 Tab 导航
- 自适应强度模型
- 题库扩充至 50-80

### 阶段三：素材与成长
- 模块一（思辨素材库 50-80 条）
- 模块四完整版（周期性报告 + 推荐）
- 模块间跳转
- 范文库（30-50 篇）

### 阶段四：打磨
- 自适应模型校准
- 内容库扩充至目标规模
- 性能优化、体验打磨

---

## 9. 设计原则

1. 不讲概念给情境
2. 不评价人只追问论证
3. 不替代思考只暴露盲区
4. 不预设素养门槛
5. 训练即考试、考试即训练
6. 不预先框定概念库，AI 根据题目动态匹配
7. 平权而非精英：用日常语言讨论深刻问题
